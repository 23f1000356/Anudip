# 🚚 Delivery Performance Analysis (Excel & Power BI Project)

## 📌 Project Overview

This project focuses on analyzing delivery operations data to evaluate performance, efficiency, and customer satisfaction. The analysis was initially conducted using **Microsoft Excel** (utilizing Pivot Tables, Charts, and Conditional Formatting) and subsequently expanded into a comprehensive **Power BI Dashboard** for advanced interactive data visualization.

---

## 📂 Dataset Information

The dataset contains 50 records of delivery orders with the following fields:

* Order_ID
* Order_Date
* City
* Delivery_Status (Delivered / Delayed / Cancelled)
* Delivery_Time_Days
* Product_Type
* Customer_Rating (1–5)
* Delivery_Partner
* Payment_Type
* Order_Value

---

## 🧹 Data Preparation

The following data cleaning steps were performed:

* Formatted date column (Order_Date)
* Checked and handled missing values
* Converted dataset into a structured table
* Created calculated columns:

  * **Delivery Category** (Fast / Medium / Slow)
  * **Rating Category** (Good / Average / Poor)

---

## 📊 Analysis Performed

### Pivot Tables Created:

1. City-wise Order Distribution

4. Delivery Partner Performance

## 📈 Charts Created:

1. Column Chart – City-wise Order Distribution

## 🎯 Key Insights

* Identified cities with the highest number of orders
* Analyzed delivery delays and cancellations

* **Microsoft Excel**

---

## 🖥️ Power BI Dashboard Overview

An interactive dashboard was built natively in Power BI, showcasing the following features:
* **KPI Metrics**: Providing immediate high-level insights such as total Order Count (50), Average Customer Rating (2.78), Average Delivery Time (5.26 Days), and Total Order Value (140K).
* **Geographical Mapping**: A Map visual illustrating the volume of orders across different cities in India (Delhi, Mumbai, Bangalore, Pune).
* **Operational Visuals**: 
  * Bar charts comparing order fulfillment among delivery partners (DHL, BlueDart, Delhivery).
  * Pie charts giving a visual breakdown of delivery status (Delayed, Cancelled, Delivered).
  * Line and Clustered Column charts tracking performance metrics over delivery times and months.
* **Dynamic Slicers**: Interactive elements on the sidebar allowing users to filter the entire dashboard by City, Delivery Status, Product Type, and Delivery Partner.
